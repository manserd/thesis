\chapter{Introduction}

Automated planning is an area in artifical intelligence research concerned with the automated solving of problems: these problems are modeled as \kw{state spaces}, where the objective is finding a \kw{solution} in the form of a sequence of states starting at an \kw{initial state} that ends in a desired \kw{goal state}.

To find these solutions, we use a \kw{search algorithm}: one such algorithm is the \kw{greedy best-first search}[GBFS] algorithm \pcite{doran1966}[whole paper], which is particularly popular in \kw{satisficing search}, where we do not concern ourselves with the number of states that make up our solution, so long as we find any solution at all.

GBFS uses a \kw{heuristic}, which approximates how close a given state is to a goal state, to guide its search. If a heuristic presents a region of the state space as more promising than it really is, it is possible for GBFS to get ``trapped'', which can significantly impact search performance. We call these regions \kw{uninformed heuristic regions}[UHRs].

One algorithm that attempts to address this issue is \kw{$\epsilon$-GBFS} \pcite{valenzano2014}[start of section 2], which uses \kw{stochastic exploration}, where we allow GBFS to occasionally ignore the advice of the heuristic and instead select a state randomly. To further improve the effectiveness of this approach, \tcite{xie2014b}[whole paper], building on work by \tcite{lelis2013}, suggested considering similar states as part of the same \kw{type}. By selecting over these types rather than states, we can achieve higher diversity upon a stochastic selection: we call this \kw{type-based stochastic exploration}.

The \kw{bench transition system}[BTS], introduced by \tcite{heusner2017}[whole paper], models a GBFS search as a sequence of steps, where at each step, GBFS' expansions are contained within a \kw{bench}, which is a state space region within which GBFS does not make ``progress'' towards a goal state. Importantly, for some kinds of UHRs, the BTS guarantees that those UHRs will be contained entirely within a single bench \pcite{tomasz2024}[Observation 3.1]. This naturally makes the BTS interesting in the context of type-based stochastic exploration, because if benches could be mapped to types, selection between types would imply selection between UHRs, at least for some kinds of UHRs.

Unfortunately, the BTS cannot be computed during search due to its reliance on the concept of \kw{high-water mark} \pcite{wilt2014}[p. 4, right]. This work presents two approximations of the BTS, the \kw{heuristic improvement transition system}[HITS] and the \kw{low-water mark transition system}[LOTS], both introduced by \tcite{tomasz2024}[whole paper], which can build types that approximate benches. We test the performance of the HITS and LOTS by comparing different variants to regular GBFS as well as to $\epsilon$-GBFS, \kw{Type-GBFS} \pcite{xie2014b}[p. 6, new section], and \kw{Softmin-GBFS} \pcite{kuroiwa2022}[whole paper], which are three established GBFS variants that perform stochastic exploration.
